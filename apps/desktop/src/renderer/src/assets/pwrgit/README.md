# PwrGit brand asset

`pwrgit-app-icon.png` is the official PwrGit application icon, copied
verbatim from the sister PwrSuite repository:

- Repository: <https://github.com/pwrdrvr/PwrGit>
- Source path: `apps/desktop/build/icon.iconset/icon_128x128@2x.png`
- Usage: the New Thread PwrGit connection prompt

To refresh it, copy the same generated iconset member from a current PwrGit
checkout. Do not redraw, recolor, or inline the mark in PwrAgent.
