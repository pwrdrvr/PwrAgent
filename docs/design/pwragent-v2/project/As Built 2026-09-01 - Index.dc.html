How this was captured

A throwaway Vite server mounted the real renderer components against the real apps/desktop/src/renderer/src/styles/app.css, driven by fixtures lifted from the vitest suites. Every number on these pages was read from the running DOM with getComputedStyle — not from reading the stylesheet.

That distinction matters. Several containers (.lens-switch, .settings-field, .thread-row) declare no font-size and inherit the 16px user-agent default, which is invisible in the stylesheet and visible in the measurement.

What the capture turned up

Three findings worth knowing before the next change. Each is reproducible from the run described above.

Directories lens has orphaned listitem semantics

Thread rows render role="listitem". In Inbox and Recents their container .sidebar-list--dense carries role="list". In Directories, .directory-row__threads carries no role and neither does any ancestor, so axe reports aria-required-parent (critical, 3 nodes). The E2E a11y gate never switches to that lens, and its KNOWN_VIOLATIONS list is empty — this is unaudited, not waived.

Log viewer misses AA contrast in both themes

Line numbers measure 3.72:1 on dark (#6b6966 on #050505) and 2.65:1 on light (#9a9792 on #f7f4ef) at 12px. The light theme's debug-collection note measures 4.4:1 (#a86b00 on white) at 11px. AA wants 4.5:1.

The lens tabs are not named what the docs call them

The five lenses ship with accessible names Attention, Drafts, Updated, Created, Directories. The internal browse-mode values are still inbox and recents, and the contributor docs still say "Inbox" and "Recents". Copy written against the docs will not match the product.
