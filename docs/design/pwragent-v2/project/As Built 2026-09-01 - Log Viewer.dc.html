Log viewer

A secondary window over a live tail of the profile's main log. Four stacked bands — titlebar, toolbar, file row, line list — and a status line between the last two. It takes no props: the whole surface is driven by one snapshot read and one subscription.

Level filters are colour-coded to the status scale

Error, Warning and Info tint from --status-error, --status-warning and --accent. Debug carries no tint, and it is off by default — a snapshot containing debug lines renders fewer rows than it holds until the operator enables the level.

Line numbers fail AA in both themes

.log-window__line-number measures 3.72:1 on dark (#6b6966 on #050505) and 2.65:1 on light (#9a9792 on #f7f4ef), both at 12px against a 4.5:1 requirement. The gutter is decorative-ish but it is real text and axe treats it as such.

In light theme the debug-collection note (.log-window__status-note, #a86b00 on white, 11px) measures 4.4:1 — close enough that a slightly darker --status-warning would clear it.

Neither is waived: the E2E a11y gate does not open this window, and its KNOWN_VIOLATIONS list is empty.

Everything here is copyable

The file path, each individual line, and the whole buffer all carry copy affordances. Log content is the thing operators paste into bug reports, so the surface is built around extraction rather than reading.
