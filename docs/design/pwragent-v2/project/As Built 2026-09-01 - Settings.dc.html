Groups open collapsed except the active route

A section hidden behind a closed caret reads as a dead nav, so the group holding the initial route opens with it. Sub-items carry a status dot (--ok / --off) rather than a count.

Titlebar and breadcrumb

The Settings titlebar and the Activity/Logs titlebar are separate primitives that must agree on colour. They do — but not on size.

Breadcrumb parts, both windows, measured side by side.

Colour contract holds, size contract does not

The theme-contract test compares the brand and breadcrumb tokens across these primitives, and those match exactly. The type sizes are one pixel apart — 12px in Settings, 13px in Activity and Logs — and nothing pins that. Worth deciding whether it is intentional before the next chrome change.

The switch is not a checkbox with a skin

No browser-default control ships in this UI. The track carries the accent border at 42% and the fill at 16% when on, and drops to the neutral strong border when off — the same two-tier border scale the rest of the app uses.

Settings is the one surface with zero axe findings

All six Settings captures — General, Models and Usage & Pricing, each in both themes — returned no violations at wcag2a through wcag22aa. It is also the only screen the E2E a11y gate already drives in both themes.
