The lens switch

Five tabs in one 32px pill. Every tab is icon-only — the name lives in aria-label and the tooltip. Attention is the exception: instead of an icon it renders two live counts.

Shipped names, not doc names

browseModeLabels in Sidebar.tsx maps inbox → "Updated" and recents → "Created". The contributor docs still call these lenses Inbox and Recents. The route values did not change; only the user-facing names did.

Zero counts stay visible

Attention renders both indicators at all times and greys them at zero rather than hiding them. A missing indicator reads as a broken tab, not an idle one.

Thread rows

One row shape serves every lens. The card is .thread-row; the open-thread control is a full-card empty overlay, so the title, chips and status marker are its siblings rather than its children — a button inside a button is invalid.

The Draft chip is viewer-local

Draft state is derived from the composer draft store on the machine that holds the text, never from the thread summary and never federated. A viewer drafting a reply to a peer's thread sees the chip; the instance that owns the thread does not.

Unread clears differently in Attention

In every browsing lens, focusing a thread clears its cookie. In Attention it does not — only an accepted reply does, reported after the backend resolves the send rather than when the operator presses it. Attention is a work queue, so a glance must not empty it.

Attention deliberately ignores updatedAt

updatedAt moves on every streamed item, sub-agent call and tool result. Sorting the queue by it would reshuffle rows under the operator's cursor mid-turn. A thread moves at most twice per turn: once when it starts, optionally once when it ends.

Directories: orphaned listitem semantics

Rows carry role="listitem" in every lens, but only Inbox and Recents wrap them in a role="list" container. In Directories, .directory-row__threads and all of its ancestors carry no role, so axe reports aria-required-parent at critical impact. The same lens also trips target-size on the selected row's open control.
