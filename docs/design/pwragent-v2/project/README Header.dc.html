README header
GitHub is the landing page for most people who arrive at PwrAgent, and the first screenful has one job: hand them the right binary. Seven chips do that — three downloads, four places to go instead. The system is PwrGit's, ported here with PwrAgent's tokens and one structural change: PwrAgent ships a fourth platform, and the row will not hold four download chips.

Two deliberate departures from the in-app token values. The hairline is .16, between --border-subtle and --border-strong, because on GitHub's #0d1117 it is the only edge separating a secondary chip from the page. The subtitle is --text-secondary rather than --text-muted, which at 11px on #0a0a0a lands near 4:1 — and the subtitle is the line that names the artifact.
Rules that decided the design
One opaque chip, not two theme variants
Every chip carries its own fill and clears contrast on white and on #0d1117 alike, so there is no <picture> and no doubled asset count. It also keeps the header correct where <picture> is ignored: npm, VS Code's preview, GitHub mobile.
Four platforms, three download chips
At the 250px display width that keeps a download label readable, four chips need 1000px against an ~836px column and would wrap. Debian and Ubuntu become a link chip — and the reason is editorial before it is geometric: Linux ships two architectures and a .deb wants install instructions, neither of which one chip can say. The 2×2 grid and a narrower chip were the alternatives; both cost more than the demotion does.
The primary is the chip that resolves
PwrGit makes Apple Silicon primary. PwrAgent cannot yet: no release carries an arm64 macOS DMG, so the loudest chip on the page would point at a releases page with no matching asset. Universal runs natively on Apple Silicon, so it is the correct answer for every Mac today — and exactly one chip is tangerine either way. One commit later swaps the styles, moves Apple Silicon to the first slot, repoints its href, and deletes the hedge sentence.
The subtitle names the build, not the benefit
“Universal · Intel + Apple Silicon”, “x64 installer”. Someone standing at a download chip is picking an artifact, and the second line is the only place that question gets answered.
Text that does not fit fails the build
A clipped label is silent in a PNG. apps/desktop/scripts/generate-readme-chips.swift measures every label against its chip and exits non-zero rather than writing one — which is what made the system safe to hand from PwrGit to a product with a longer name and a fourth platform.
Only brand and chips diverge
Everything below those two declarations is byte-identical to PwrGit's copy, verified by diff at port time. A fix to the renderer — a metric, an icon, the fit check — can be moved between the repositories without a merge. Keep it that way.
