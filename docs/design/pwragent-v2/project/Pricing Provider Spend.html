B2Option A — one section, rows that open

Both blocks collapse into a single Spend by model section inside the card. Each row is one (provider, model) bucket: model name, provider and row count, cost. Default collapsed. Opening a row shows that model’s token volume — which is how the parent-only section gets absorbed rather than deleted: the parent’s own row carries exactly what Parent model token volume used to show, and every helper now has the same thing for the first time.

The disclosure is the rail’s existing one. Chevron, label, right-aligned figure, 120ms rotate — the same shape as the per-turn .pricing-token-miser fold two sections down, so the tab has one way of opening things instead of two.

B4The case that motivated it — Grok parent, four reviewers

Sol and Terra on OpenAI, Kimi on Moonshot, Qwen on Alibaba, Grok driving the thread. Five models, four providers, eight usage rows. Today this renders four “By provider” lines and four cards underneath — eight lines of chrome for four numbers, with the two OpenAI reviews melted into one row you cannot take apart.

Collapsed, option A is five lines and reads top-down as a spend ranking. B4·a adds a provider header only where a provider contributed more than one model — that is the one place a provider subtotal is not already a row. B4·b drops headers entirely and keeps the provider in each row’s meta. B4·a is worth the extra line: reconciling against an invoice is a per-provider question, and it is the only shape that answers it.

Watch for: formatPricingProviderLabel only maps openai, qwen, and xai; everything else falls through unformatted, which is why Moonshot renders lowercase below. Worth fixing in the same change.

B5One model — the case that must not regress

Most threads use one model. Today they get Parent model token volume and no provider list at all, and the new section must not take that away or bury it behind a click that reveals a row equal to the total above it.

The rule is one line: a lone row starts open. Same component, same markup — the collapsed state simply has nothing to hide. The result is what ships today plus the model name and the provider, which the section previously never said out loud.
