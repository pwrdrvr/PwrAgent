Proposed — line-height: normal

Put the fix on the element whose overflow does the clipping, and let the font size the box. normal measures 13.0px — the ink box exactly — so nothing clips and the text centers in the pill (ink at 4.5px in a 20px interior). A hand-picked ratio does not: 1.35 gives a 14.2px box and leaves the glyphs 0.59px high. Same remedy the codebase already uses at .review-chip__label. No chip dimension changes.
