Star Map and Messaging Activity

Two screens that each open in their own window and each break the shell's rules on purpose. Star Map is the only surface in the product with a spatial canvas; Activity is the only one built as a pure append-only feed.

The top band is contended space

Window chrome and the filter strip occupy the same band. New map controls go top-right; anything added top-left collides with the brand mark and the find affordance.

Zero counts stay visible here too

Every filter chip renders its count even at zero, greyed — the same rule the Attention lens follows. Four of the five chips read zero in this capture and all four remain on screen.

Identifiers stay literal

Channel names, actor handles and kind identifiers render exactly as the source system spells them — #agents, inbound-rejected, telegram:pwragent-ops. No title-casing, no friendly aliases. An operator matching a row against a log line has to see the same string.

The activity list is scrollable but not focusable

axe reports scrollable-region-focusable (serious) on the top pane's list in both themes: the region scrolls but no keyboard user can reach it. Rows themselves are reachable, so this bites a screen-reader user paging through a long backlog.
